# Recorded organ

A chapel organ (manual 3, quiet stop) sampled by **Simon Dalzell** (Ivy
Audio), Winter 2015-16, for **Versilian Studios Chamber Orchestra 2:
Community Edition**: <https://github.com/sgossner/VSCO-2-CE>
(`Keys/Organ/Quiet`, files `NT5_Man3Quiet_122…170_rr1.wav`).

Licence: **CC0 1.0** (public domain). "Credit to both original author and
Versilian Studios is encouraged" (the library's Info.txt), so they are
credited in the app's About panel.

17 notes, C2 to C6 every three semitones, processed by
`tools/build_corpus.py`: left microphone, trimmed, pitch measured, loop
with a baked crossfade, levelled, Ogg Opus 80 kbps. `corpus.json` lists each
note's measured pitch, loop points and source file (with its SHA-256).
